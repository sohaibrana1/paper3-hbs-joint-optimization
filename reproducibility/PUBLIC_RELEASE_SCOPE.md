# Public release scope

This repository is a curated publication-supporting reproducibility package.

It intentionally excludes large intermediate development searches, temporary
disassembly output, exploratory diagnostics, local build artifacts, and
redundant evidence generated during development.

The complete internal evidence chain remains in the underlying research project.

The public package retains publication-relevant protocols, manuscript materials,
final validation records, final WOTS+C security-proof artifacts, publication
tables and figures, selected source snapshots, and SHA-256 manifests.

Experimental WOTS+C configurations are research extensions and must not be
represented as standardized XMSS or XMSSMT parameter sets.

Conditional numerical WOTS+C security estimates do not constitute an
unconditional numerical security claim for the real SHA-256 construction.
