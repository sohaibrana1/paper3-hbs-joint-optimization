# Joint Optimization of Hash-Based Signatures for Resource-Constrained Devices

Reproducibility materials for the Paper 3 joint-optimization study.

## Authors
- Sohaib Rana
- Mohd Najwadi Yusoff
- Je Sen Teh
- Adnan Anwar

## Scope
- XMSS/XMSSMT parameter optimization
- experimental WOTS+C evaluation
- signature-size reduction
- compact state management
- alternative hash backends
- memory-oriented optimization
- parallel execution
- cross-platform evaluation
- combined multi-objective optimization

## Security note
Experimental WOTS+C and alternative-hash configurations are research extensions
and must not be interpreted as standardized XMSS/XMSSMT parameter sets.

The manuscript distinguishes a symbolic standard-assumption WOTS+C theorem from
a conditional idealized numerical corollary. The latter is not an unconditional
numerical security claim for the real SHA-256 construction.
